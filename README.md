## How it's built

Plain HTML, CSS and JavaScript on GitHub Pages, with no framework and no build step.

- A WebGL sky that follows your local time (day, night, seasons, moon phase). On machines without a graphics card it paints once and holds still, to keep the page responsive.
- Self-hosted fonts (Instrument Serif, Geist, Geist Mono) and WebP images, lazy-loaded below the fold
- Accessible: text at least 13px, tap targets at least 44px, respects reduced motion, and works with keyboard and screen readers
- SEO: schema.org Person/ProfilePage data, sitemap, Open Graph tags, and verified in Google Search Console and Bing
